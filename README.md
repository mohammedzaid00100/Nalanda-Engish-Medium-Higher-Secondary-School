# Nalanda English Medium Higher Secondary School — Website Demo

A student-developed, multi-page demo redesign for Nalanda English Medium Higher Secondary School in Bhilai, built to demonstrate a modern school information website.

## Content and features

- Academics and admissions information.
- Campus and student-life sections.
- School rules, disclosures and contact information.
- Responsive pages built with HTML, CSS, JavaScript and JSON.

## Status

The project is a **student-developed demo**, paused pending official school information and a response. It should not be presented as the school's officially adopted website.

[View demo](https://nemhss.netlify.app/)
